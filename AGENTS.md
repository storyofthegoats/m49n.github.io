# m49n magazine

Use the 1959 Topps Setbuild header and sidebar on m49n magazine subpages unless the user directs otherwise. Load the shared `issue-layout.css` and `issue-layout.js` assets and follow the markup in `1959-v1-5.html` or `hemingway/index.html`. Use the page's own section links in the sidebar and include a link back to the issue cover. The cover has its own layout.
